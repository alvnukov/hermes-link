# Настройки плагина в Hermes Desktop

Плагин `http-mcp` использует штатную форму Hermes Desktop, построенную по `config_schema` из `plugin.yaml`. Откройте раздел возможностей, вкладку плагинов, выберите профиль, в котором установлен `http-mcp`, и нажмите значок шестерёнки возле плагина. Настройки доступны и при выключенном плагине.

| Поле | По умолчанию | Что меняет |
| --- | --- | --- |
| Разрешить изменения | Включено | Разрешает запуск агентов и изменение задач, профилей, расписаний и настроек. Выключенное поле оставляет доступ только к инструментам чтения. |
| Проверять токен доступа | Включено | Требует Bearer-токен для HTTP-запросов. Можно выключить для локального подключения без токена. Сервер слушает только `127.0.0.1`. На транспорт stdio эта проверка не распространяется. |
| Токен доступа | Значение скрыто | Поле пароля для ввода или замены Bearer-токена. Сохранённое значение не возвращается в форму. |
| Отдельные действия | Все 39 включены | По одному переключателю на каждую операцию. Прежние имена, например `hermes_run`, сохранены как ключи настроек. Выключенное действие скрывается из справки компактного инструмента и не вызывается через него. |

Например, чтобы запретить запуск агентов и полную замену конфигурации, выключите «Запускать задачи агентов» и «Применять полную конфигурацию Hermes». Для доступа только к чтению выключите общий переключатель «Разрешить изменения». Отдельный включённый инструмент не обходит это общее ограничение.

Начиная с 0.6.0 MCP публикует 10 инструментов по областям; каждый принимает
`action` и `params`. Например, переключатель `hermes_run` управляет действием
`run` инструмента `hermes_tasks`, а `hermes_kanban_create` — действием `create`
инструмента `hermes_kanban`. Если в группе не остаётся доступных действий, весь
инструмент исчезает из discovery. При `writes: false` действия записи исключаются
из discovery/справки, чтение сохраняется, запись также запрещена при прямом вызове.
Полная таблица и формат справки — [compact-tools.md](compact-tools.md).

В поле «Токен доступа» введите 32–256 символов `A–Z`, `a–z`, `0–9`, `_` или `-`. Hermes сохраняет токен через штатный механизм секретов в переменную `HERMES_HTTP_MCP_TOKEN` файла `.env` выбранного профиля. Токен не записывается в `config.yaml` или `config.json`, не попадает в данные формы и не показывается после сохранения. Пустое поле оставляет существующий секрет без изменений.

При включённой проверке токена MCP сначала читает `HERMES_HTTP_MCP_TOKEN` из `.env` своего профиля. Если файл или эта переменная отсутствуют, используется прежний `token_file` из конфигурации запуска. Переменная окружения процесса не используется как запасной источник. Некорректный сохранённый токен останавливает запуск HTTP MCP. Файлы секретов должны принадлежать текущему пользователю, быть обычными файлами и не давать прав другим пользователям; штатный писатель создаёт `.env` с правами `0600`.

Нажмите «Сохранить», затем перезапустите **процесс HTTP MCP**. Сохранение в Desktop не перезапускает этот отдельный процесс. Уже запущенный MCP продолжает использовать настройки, прочитанные при запуске; клиенту может потребоваться повторное подключение, чтобы обновить список инструментов. После замены токена задайте в клиенте тот же новый Bearer-токен. Сохранение в UI не обновляет заголовки клиента и не переключает туннель автоматически. Скрипт переустановки создаёт локальный файл заголовка из действующего токена и сохраняет ключ, заданный в UI.

Hermes сохраняет переключатели через свой `save_plugin_settings` в `plugins.entries.http-mcp.settings` файла `config.yaml` выбранного профиля. Секретное поле сохраняется отдельно штатным маршрутом учётных данных. MCP читает явно сохранённые переключатели через строгий штатный `require_readable_config_before_write(get_config_path())` из профиля, заданного `board_profile` в конфигурации запуска. В том же профиле определяется путь `.env`. Выберите в Desktop этот профиль. При отсутствии `board_profile` используется `default`.

Порядок применения: сначала загружается файл, переданный через обязательный `--config`, затем явно сохранённые `writes` и `auth_enabled` заменяют соответствующие значения. Прежний список `disabled_tools` в конфигурации запуска или сохранённых настройках поддерживается, хотя JSON-поле больше не показывается в форме. Явно сохранённый переключатель `tool_<имя инструмента>` имеет приоритет для этого инструмента: включение убирает его из прежнего списка исключений, выключение добавляет. Несохранённые поля сохраняют значения конфигурации запуска. Скрипт установки заполняет отсутствующие переключатели действующими значениями, чтобы после установки или переустановки форма отражала ограничения; уже сохранённые переключатели сохраняются. Адрес, порт, файл запасного токена, доступные профили и доски, а также лимит одновременных запусков остаются параметрами конфигурации запуска.

Этот порядок одинаков для команды `hermes http-mcp --config …` и прямого запуска `python -m hermes_bridge.main --config …`. Регистрация плагина только добавляет CLI-команду; HTTP MCP запускается отдельной командой. Некорректные типы сохранённых переключателей или неизвестные имена инструментов останавливают запуск до открытия слушателя.

Повреждённый или нечитаемый `config.yaml`, а также неверный тип любого присутствующего раздела `plugins`, `entries`, `http-mcp` или `settings` останавливают запуск. Значения по умолчанию и предыдущая исправная версия файла не используются вместо повреждённых настроек. При корректном файле строгий читатель не создаёт каталоги или резервные копии. При ошибке YAML штатный механизм Hermes может сохранить копию повреждённого файла в `backups/config/` и вывести локальную диагностику; MCP сообщает об остановке общим сообщением без содержимого ошибки разбора.

Форма использует штатные функции Hermes для описания полей и сохранения настроек.
Их совместимость проверяется интеграционными тестами на временных профилях.
Команды проверки описаны в [CONTRIBUTING.md](../CONTRIBUTING.md).
